# Region RP — Панель Ивентов

## Как запустить
1. Скачай/создай все файлы в папке `region-rp/` согласно структуре.
2. Открой `index.html` в браузере (лучше через Live Server в VS Code или любой локальный сервер, чтобы избежать проблем с localStorage).
3. Войди как админ по умолчанию:
   - Логин: `mummiya`
   - Пароль: `mummiya`

## Что внутри
- **index.html** — экран входа/регистрации.
- **dashboard.html** — основная панель (ивенты, состав, топ, карцер, мероприятия).
- **css/style.css** — общие стили тёмной темы.
- **css/auth.css** — стили для экрана авторизации.
- **js/data.js** — работа с localStorage (пользователи, ивенты, МП, карцер).
- **js/auth.js** — логика входа/регистрации.
- **js/dashboard.js** — навигация по разделам и рендер.
- **js/events.js** — создание/завершение ивентов, модалка помощников.
